Cryptography · Quantropi

Finding randomness
in the everyday.

I co-authored research on QPP-RNG, a true random number generator that draws entropy from subtle system timing variations on everyday hardware.

My work connected C implementation, Python analysis, statistical evaluation, and testing across Windows, macOS, and Raspberry Pi.

  • C
  • Python
  • NIST SP 800-90B
  • NIST SP 800-22
  • Cross-platform testing
Read the published paper

Vrana, G., Lou, D. & Kuang, R. Raw QPP-RNG randomness via system jitter across platforms: a NIST SP 800-90B evaluation. Scientific Reports 15, 27718 (2025).
